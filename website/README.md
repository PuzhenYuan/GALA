# GALA project website

Website: https://PuzhenYuan.github.io/GALA/

Edit index.html, style.css, and script.js in this website directory. The GALA Pages workflow publishes these files and the existing media assets to GitHub Pages. Only the assembled website is published; the code repository remains private.

Media assets are copied at build time from anonymity35/GALA at the fixed revision 6d832d928f2873668954d4534abaa308eda06562. Published media are served from this website, not loaded from the anonymous website by visitors. To update media, update the revision in .github/workflows/gala-pages.yml or add local media and update its assembly step.
